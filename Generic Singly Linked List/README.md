# Generic Singly Linked List

Шаблонный односвязный список на C++17 — упрощённый аналог `std::forward_list` с STL-совместимыми итераторами и гарантиями безопасности исключений.

## Возможности

- Шаблонный класс `SingleLinkedList<Type>` для любого типа с конструктором копирования.
- Forward-итераторы двух видов: `Iterator` (изменяемый) и `ConstIterator` (только чтение), оба из одного шаблона `BasicIterator`. `Iterator` неявно преобразуется в `ConstIterator`, итераторы можно сравнивать между собой.
- Работа со стандартными алгоритмами и range-based for: `std::equal`, `std::lexicographical_compare` и т. д.
- Фиктивный узел перед первым элементом: итератор `before_begin()` позволяет вставлять и удалять в начале списка теми же методами, что и в середине.
- Вставка и удаление после произвольной позиции за O(1).
- Строгая гарантия безопасности исключений для `PushFront`, `InsertAfter`, `operator=` и конструкторов: если копирование элемента выбросило исключение, список остаётся в прежнем состоянии, а уже созданные узлы освобождаются.
- Проверка предусловий через `assert`: разыменование `end()`, `PopFront` у пустого списка, `EraseAfter` у последнего элемента.
- Копирующее присваивание через идиому copy-and-swap, обмен содержимым за O(1) без копирования узлов.
- Полный набор операторов сравнения (`==`, `!=`, `<`, `<=`, `>`, `>=`), лексикографическое сравнение.

## Интерфейс

| Метод | Описание | Сложность |
|---|---|---|
| `PushFront(value)` | вставка в начало | O(1) |
| `PopFront()` | удаление первого элемента | O(1) |
| `InsertAfter(pos, value)` | вставка после `pos`, возвращает итератор на новый элемент | O(1) |
| `EraseAfter(pos)` | удаление элемента после `pos`, возвращает итератор на следующий | O(1) |
| `Clear()` | удаление всех элементов | O(N) |
| `GetSize()` / `IsEmpty()` | размер и проверка на пустоту | O(1) |
| `swap(other)` | обмен содержимым с другим списком | O(1) |
| `begin()` / `end()` / `cbegin()` / `cend()` | итераторы на начало и конец | O(1) |
| `before_begin()` / `cbefore_begin()` | итератор на позицию перед первым элементом | O(1) |

Конструкторы: по умолчанию, из `std::initializer_list`, копирующий.

## Пример

```cpp
SingleLinkedList<int> list{1, 2, 3};

list.InsertAfter(list.before_begin(), 0);   // 0 1 2 3
list.InsertAfter(list.begin(), 10);         // 0 10 1 2 3
list.EraseAfter(list.cbegin());             // 0 1 2 3
list.PopFront();                            // 1 2 3

for (int x : list) {
    std::cout << x << ' ';
}

SingleLinkedList<int> copy = list;
assert(copy == list);
assert((SingleLinkedList<int>{1, 2} < list));
```

## Как устроено

```
 head_ (фиктивный)
[      ] --> [ 1 ] --> [ 2 ] --> [ 3 ] --> nullptr
    ^          ^                             ^
before_begin  begin                         end
```

Вставка после `pos` сначала создаёт новый узел и только затем меняет связи списка. Поэтому исключение при создании узла (нехватка памяти или ошибка в конструкторе копирования `Type`) не затрагивает список.

Конструкторы копирования и из `initializer_list` собирают узлы во временном списке и в конце обмениваются с ним через `swap`. Если копирование прервётся исключением, деструктор временного списка удалит уже созданные узлы, и утечки памяти не будет.

## Структура проекта

```
├── single-linked-list.h   реализация SingleLinkedList (header-only)
└── main.cpp               тесты Test0–Test4
```

## Сборка и запуск

```bash
clang++ -std=c++17 -Wall main.cpp -o linked_list
./linked_list
```

Программа запускает тесты `Test0`–`Test4` на `assert`. Они проверяют итераторы, копирование, присваивание, сравнение, удаление элементов (через объекты-шпионы, считающие вызовы деструктора) и поведение при исключениях (через тип, бросающий исключение при N-м копировании).

## Технологии

- C++17, шаблоны классов
- ручное управление памятью (`new` / `delete`)
- итераторы в стиле STL (`std::forward_iterator_tag`, `[[nodiscard]]`, `noexcept`)
- идиома copy-and-swap
- гарантии безопасности исключений

## Ограничения

- Нет указателя на последний элемент, поэтому вставка в конец работает за O(N).
- Поддерживается только копирование элементов; семантика перемещения не реализована.
