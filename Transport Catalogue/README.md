# Transport Catalogue

Консольный транспортный справочник на C++17: хранит остановки с координатами и автобусные маршруты двух видов, отвечает на запросы статистики о них. Данные читаются из `stdin`, результат пишется в `stdout`.

## Возможности

- Добавление остановок с географическими координатами: `Stop Marushkino: 55.582625, 37.653910`.
- Добавление маршрутов двух видов:
  - кольцевой через `>`: `Bus 256: A > B > C` — последовательность остановок используется как есть;
  - линейный через `-`: `Bus 750: A - B - C` — маршрут разворачивается в обе стороны (`A B C B A`).
- Статистика по маршруту: количество остановок, количество уникальных остановок, длина маршрута в метрах, вычисленная по координатам соседних остановок.
- Статистика по остановке: список маршрутов, проходящих через неё, в алфавитном порядке.
- Ответы на запросы к несуществующим маршрутам (`not found`) и остановкам без маршрутов (`no buses`).

## Формат ввода-вывода

Вход: количество базовых запросов, сами базовые запросы (`Stop` / `Bus` по одному на строку), затем количество запросов статистики и сами запросы.

| Запрос | Ответ |
|---|---|
| `Bus 256` | `Bus 256: 3 stops on route, 2 unique stops, 56266.4 route length` |
| `Stop Marushkino` | `Stop Marushkino: buses 256 750` |
| `Bus 751` (нет такого) | `Bus 751: not found` |
| `Stop Nezhinskaya` (нет маршрутов) | `Stop Nezhinskaya: no buses` |

## Пример

Вход:

```
5
Stop Tolstoy Street: 55.611087, 37.208960
Stop Marushkino: 55.582625, 37.653910
Bus 256: Tolstoy Street > Marushkino > Tolstoy Street
Bus 750: Tolstoy Street - Marushkino
Stop Nezhinskaya: 55.612302, 37.693123
4
Bus 256
Bus 750
Bus 751
Stop Nezhinskaya
```

Выход:

```
Bus 256: 3 stops on route, 2 unique stops, 56266.4 route length
Bus 750: 3 stops on route, 2 unique stops, 56266.4 route length
Bus 751: not found
Stop Nezhinskaya: no buses
```

## Как устроено

```
input_reader                stat_reader
    ParseLine / ApplyCommands    ParseAndPrintStat
          │                            │
          ▼                            ▼
        TransportCatalogue
        ├── stops_      deque<Stop>          остановки
        ├── buses_      deque<Bus>           маршруты
        ├── stop_index_ / bus_index_         unordered_map<string_view, T*>
        └── stop_to_buses_                   остановка → множество маршрутов
```

- Остановки и маршруты хранятся в `std::deque` — адреса элементов не меняются при добавлении новых, поэтому индексы строятся на `std::string_view` и указателях без копирования строк.
- `input_reader` сначала разбирает все строки в команды, а при применении выполняет все `Stop` раньше всех `Bus` — маршруты ссылаются на уже добавленные остановки.
- Разбор строк работает на `std::string_view`: подстроки не копируются, копирование происходит только при сохранении в каталог.
- Длина маршрута — сумма расстояний между соседними остановками: в `geo.h` координаты переводятся в радианы и считается длина дуги большого круга (радиус Земли 6371 км).

## Структура

```
Transport Catalogue/
└── transport-catalogue/
    ├── geo.h                    координаты и расстояние между точками
    ├── transport_catalogue.h    интерфейс каталога
    ├── transport_catalogue.cpp  хранение остановок, маршрутов и индексов
    ├── input_reader.h
    ├── input_reader.cpp         разбор базовых запросов
    ├── stat_reader.h
    ├── stat_reader.cpp          запросы статистики и вывод
    └── main.cpp                 точка входа
```

## Сборка и запуск

```bash
clang++ -std=c++17 -Wall -Wextra transport-catalogue/*.cpp -o transport_catalogue
./transport_catalogue < input.txt
```

## Технологии

- C++17: `std::string_view`, if-инициализация
- `std::deque` как хранилище со стабильными адресами элементов
- `std::unordered_map` / `std::unordered_set` / `std::set` для индексов
- вычисление расстояния между координатами по дуге большого круга

## Ограничения

- Длина маршрута считается географически, по координатам остановок, а не по реальным дорожным расстояниям.
- Поддерживается только текстовый протокол ввода-вывода, без JSON.
- Остановки в маршруте считаются добавленными заранее; запросы с неизвестными остановками не обрабатываются.
