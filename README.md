# Пет-проекты на C++

Четыре проекта на C++: от учебных контейнерных структур до приложений с графическим интерфейсом. Подробное описание, примеры и инструкции по сборке — в README каждого проекта.

| Проект | Что это | Стек |
|---|---|---|
| [C++ Include Preprocessor](<C++ Include Preprocessor/README.md>) | Консольная утилита, рекурсивно раскрывающая директивы `#include` с поиском по include-директориям и сообщениями об ошибках — упрощённый аналог этапа включения препроцессора C++. | C++17, `std::filesystem`, `std::regex` |
| [Deque emulator](<Deque emulator/README.md>) | Десктопное приложение, наглядно показывающее работу `std::deque`: методы контейнера, управление итератором, алгоритмы STL и собственная шаблонная сортировка слиянием. | C++20, Qt 6 Widgets |
| [Generic Singly Linked List](<Generic Singly Linked List/README.md>) | Шаблонный односвязный список — упрощённый аналог `std::forward_list`: STL-совместимые итераторы, вставка через `before_begin`, строгие гарантии безопасности исключений. | C++17, шаблоны, итераторы STL |
| [Transport Catalogue](<Transport Catalogue /README.md>) | Консольный транспортный справочник: хранит остановки и автобусные маршруты (кольцевые и линейные), отвечает на запросы статистики по маршрутам и остановкам. | C++17, `std::string_view`, `std::deque` |
